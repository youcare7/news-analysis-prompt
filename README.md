深度新闻分析 Prompt - 宏观透视 + 个体生存行动指南

> 基于「倡导-缺失」反向透视法 · 让AI帮你看穿新闻表象、找到个体出路的分析框架。

---

## 💡 核心原理
> **"主流媒体反复倡导的东西，往往不是答案，而是社会的症状。"**
>
> **"在宏大叙事中，个体的最优策略不是对抗叙事，而是在理解叙事的基础上，找到属于自己的生存缝隙。"**

---

## 📖 使用示例

### 示例：分析"境外势力煽动躺平"新闻

**输入：**
> 2026年4月28日，国家安全部发布文章《煽动"躺平"的他们，正忙得脚不沾地》，揭露境外反华敌对势力借助网络平台，渲染"努力无用""奋斗吃亏"等消极观念...

**输出：**

#### 一、新闻摘要
国安部披露境外势力资助"躺平网红"进行意识形态渗透（2026.4.28）

#### 二、宏观分析
1. **倡导信号**：倡导"警惕躺平""保持奋斗"
2. **社会症状诊断**：青年群体中存在普遍的焦虑、对奋斗价值的怀疑
3. **宏大叙事解构**：将个体情绪问题上升为敌我矛盾
4. **叙事框架分析**：弱化国内结构性压力

#### 三、个体处境评估
- **位置定位**：普通青年，既感受压力又不希望被标签化
- **策略选择**：D（长期筑基）+ B（低调避险）

#### 四、个体行动建议
- **立即**：区分"情绪宣泄"和"价值否定"
- **三个月**：建立多元信息源
- **一年**：提升核心竞争力
